# Changelog

All notable changes to GDA are documented here.

## [2.0.0] - 2026-09-16

- Rebuilt the university final-year project as a clean Django and React monorepository.
- Added role and object-level authorisation, protected session authentication and private evidence handling.
- Added a PostGIS radius query and an interactive Leaflet location picker.
- Added deterministic synthetic demo data through `seed_demo_data`.
- Expanded frontend component tests and added Playwright E2E journeys.
- Added backend and frontend coverage reporting with CI thresholds.
- Added reproducible Docker Compose services, automated validation and tagged GHCR image publishing.
- Licensed the project under the MIT Licence.
